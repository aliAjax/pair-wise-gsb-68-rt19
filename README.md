# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- **共享来源库**：采访材料一次入库、多条主张/事实复用，每条来源登记授权编号与授权范围版本。
- **授权范围联动失效**：法务改动授权范围（scopeVersion 抬升）或撤权后，旧范围确认过的关联事实立即失效、等待重新确认；其他事实照常。
- **事实重新确认**：按当前授权版本重新登记；含已撤销授权时不可重认，须更换来源或恢复授权。
- **发布快照锁定**：发布时把当时的事实与来源逐条深拷贝锁定为不可变档案；此后授权或来源变更不改写历史档案。
- **重认前停止导出**：存在失效待重认事实时，主张档案与全量档案导出均被拦截；已锁定的发布档案仍可单独导出。
- **撤权/发布两窗口撞车**：进入发布窗口即按当时授权版本占锁；若撤权窗口同期改动，提交发布时发布一侧先停、退回编辑复核（跨标签页经 storage 事件同步）。
- **旧稿迁移**：内嵌采访材料迁入共享库并补授权编号，写入迁移检查点；本机写入失败后从检查点恢复，只补未完成事实与审计，步骤与审计去重、不重复记录；历史档案不改写。
- 证据关系图、来源时间线、多人批注、授权范围变更记录、迁移检查点与完整不可变审计导出。

端口为`18468`。

```bash
npm install
npm run build
npm run dev
```

## 演示路径

1. 「授权与来源库」对 `AUTH-2026-018` 改范围或撤权，观察主张 `FC-260929-01` 中 F-1/F-2 立即变红待重认、F-3 照常。
2. 回到主张页对可重认事实「按当前授权范围重新确认」；失效期间「导出档案」按钮停止导出。
3. 「编辑复核」对一条待发布主张点「模拟另一窗口撤权（撞车演练）」再「提交发布」，发布侧先停并退回复审。
4. 打开旧稿 `FC-260930-04`，先「模拟本机写入失败」，再用检查点「恢复」，核对审计中补授权编号不重复。
5. 「档案与审计」可随时单独导出已发布档案 `PUB-FC-260928-03` 的锁定快照。
